# Security Policy

## Reporting a Vulnerability
If you find a security vulnerability in this project, please report it privately using GitHub’s **Private vulnerability reporting** feature.

Do not disclose the issue publicly until it has been reviewed and addressed.

## Supported Versions
Only the latest release is actively supported. Older versions may not receive security updates.

## Response Process
As this is a personal open-source project, response times may vary.  
I will review the report and take appropriate action as soon as possible.

# セキュリティポリシー（日本語版）

## 脆弱性の報告について
このプロジェクトで脆弱性を発見した場合は、GitHub の **Private vulnerability reporting** 機能を利用して、非公開で報告してください。

問題が確認・修正されるまでは、公開で共有しないようお願いします。

## サポート対象バージョン
サポート対象は最新リリースのみです。  
古いバージョンにはセキュリティ更新が提供されない場合があります。

## 対応プロセス
個人開発のため、対応速度は状況により変動します。  
可能な限り迅速に確認し、必要な対応を行います。
